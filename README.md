# Mental Arithmetic Trainer

A lightweight Python game for improving mental arithmetic speed and accuracy.
Practise addition, subtraction, multiplication, and division in either a
Tkinter desktop interface or the terminal. The project uses only Python's
standard library.

## Features

- Addition, subtraction, multiplication, and exact integer division
- Configurable operation-specific operand ranges in the GUI
- Countdown-based training sessions and live scoring
- Automatic answer detection without Enter or a Submit button
- Normal text editing with Backspace, Delete, cursor movement, and selection
- Response-time and correction tracking
- One CSV history file per session, grouped by local calendar date
- Performance summaries and arithmetic weakness analysis

Subtraction questions are generated by reversing addition problems, which
keeps answers positive. Division questions reverse multiplication problems, so
their answers are always integers.

## Requirements

- Python 3.8 or newer
- Tkinter for the desktop interface

Tkinter is bundled with many Python installations. On Debian or Ubuntu, it can
usually be installed with:

```bash
sudo apt install python3-tk
```

No third-party Python packages are required.

## Download and run

Download the repository as a ZIP file or clone it, then open a terminal in the
project directory:

```bash
git clone <repository-url>
cd mental_arithmetic_trainer
```

Start the graphical version:

```bash
python3 -m arithmetic_trainer.gui
```

On Windows, use `python` instead of `python3` if that is how Python is installed.

## How answer entry works

The GUI continuously observes the answer field. It advances immediately only
when the entered integer is correct.

For example, if the answer is `804`, typing `8`, then `80`, then `804` keeps the
same question visible until the final digit is entered. If you type `805`, the
question remains visible so you can correct it using normal text-field editing.

There is no Submit button, no need to press Enter, and no interrupting success
dialog between questions.

## Session settings

The GUI provides two independent operand ranges for each operation family:

```text
Addition:       [minimum] to [maximum] + [minimum] to [maximum]
Subtraction:    Addition problems in reverse
Multiplication: [minimum] to [maximum] × [minimum] to [maximum]
Division:       Multiplication problems in reverse
```

Select any combination of operations, choose the session duration, and start
training. All range values must be positive integers, with each minimum no
greater than its corresponding maximum.


## Training history

The application creates a separate CSV for each session and groups sessions by
the local calendar date:

```text
history/
├── 2026-10-07/
│   ├── session_1.csv
│   └── session_2.csv
└── 2026-10-08/
    └── session_1.csv
```

History contains the question, response time, outcome, correction count, and
whether the answer was entered cleanly. The `history/` directory is ignored by
Git so personal training data is not published.

Analyze all saved sessions with:

```bash
python3 -m arithmetic_trainer.analysis history
```

Analyze a specific session with:

```bash
python3 -m arithmetic_trainer.analysis history/2026-10-08/session_1.csv
```
